# NovaLink

Communications protocol for Project Solaris: frame format, message definitions, the code generator, and the hand-written cryptography — no third-party crypto libraries.

Consumed by [Nebula](https://github.com/baremetalaviator/Nebula) and [Observa](https://github.com/baremetalaviator/Observa) as a pinned git submodule — nothing depends on this repo's latest commit directly.

Part of Project Solaris: [Vanguard](https://github.com/baremetalaviator/Vanguard) (hardware) · [Nebula](https://github.com/baremetalaviator/Nebula) (firmware) · [Observa](https://github.com/baremetalaviator/Observa) (ground station)
